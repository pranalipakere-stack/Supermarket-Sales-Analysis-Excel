# Supermarket Sales Analysis – Excel Dashboard

## Project Overview
This project analyzes supermarket sales data using Microsoft Excel. It presents key business metrics and visual insights through an interactive dashboard.

## Tools Used
- Microsoft Excel
- PivotTables
- PivotCharts
- Excel formulas
- Data cleaning and formatting

## Key Performance Indicators (KPIs)
- Total Revenue
- Average Sale
- Highest Sale
- Lowest Sale
- Total Transactions

## Dashboard Analysis
The dashboard includes four visualizations:
- Revenue by Product Line
- Revenue Share by Branch
- Revenue Share by Payment Method
- Revenue by Customer Gender

## Key Insights
- Total revenue was approximately **322,966.75**.
- The dashboard compares revenue across six product lines.
- Branch performance is compared across three branches.
- Cash, credit card, and e-wallet payments are analyzed.
- Revenue is compared between female and male customers.

## Files Included
- `Supermarket_Sales_Analysis.xlsx` – Excel workbook containing the sales summary, PivotTables, charts, and dashboard.
- `supermarket_sales.csv` – Original dataset used for the analysis.
- `dashboard.png` – Screenshot of the completed dashboard.

## Purpose
This project demonstrates practical Excel skills for data cleaning, sales analysis, KPI reporting, and dashboard creation.
